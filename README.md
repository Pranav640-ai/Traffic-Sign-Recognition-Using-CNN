In this project, I experimented with different convolutional neural network architectures to classify traffic signs from the GTSRB dataset. I started with the basic model discussed in the lecture, which included a single convolutional and pooling layer, but the accuracy was limited. I then added an additional convolutional and pooling layer and increased the dense hidden layer size to 256 units, which significantly improved performance. When I increased the number of filters in the first convolutional layer to 128, the accuracy worsened, and adding another convolutional layer further reduced performance, likely due to increased model complexity and overfitting. The best results were achieved using two convolutional layers with 64 filters each and a dense layer of 256 units, reaching a test accuracy of approximately 95.58%.
